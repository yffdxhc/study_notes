# 修订记录 · 说明

> 本文件夹集中存放**所有笔记的修订记录**。
> **文件夹本身是隐藏的**，因此不影响正文阅读；正文保持干净，只留最终结论。

---

## 为什么单独放

| 好处 | 说明 |
|---|---|
| **正文干净** | 打开笔记直接看结论，不用先划过一堆"改了什么" |
| **可追溯** | 想核对"这句话是哪来的、改过几轮"时，随时能翻 |
| **集中管理** | 不用在每个目录里找 `.*-修订记录.md` 这种散落的隐藏文件 |
| **不丢信息** | 勘误过程本身有价值（比如"AI 说错了什么、以什么为准"） |

---

## 命名规则

```
{正文所在目录}-{正文文件名}.md
```

例：

| 正文 | 修订记录 |
|---|---|
| `在岗学习/Android开机流程.md` | `在岗学习-Android开机流程.md` |
| `在岗学习/AOSP源码路径导读-PiP小窗.md` | `在岗学习-AOSP源码路径导读-PiP小窗.md` |
| `在岗学习/锁屏闪屏-源码与日志定位.md` | `在岗学习-锁屏闪屏源码与日志定位.md` |

> 名字里带目录前缀，是为了**一眼看出属于哪个模块**，同时避免不同目录的同类文件名冲突。

## 约定（以后照做）

- 正文里**不再出现**"修订记录""勘误"之类的章节或链接
- 每次改动在对应记录里**追加一个批次**，不覆盖历史
- 每个批次写清楚：**改了什么 / 为什么改 / 哪些没动**
- 涉及事实核对时，注明**以什么为准**（逐字稿、AOSP 源码、实测日志）
