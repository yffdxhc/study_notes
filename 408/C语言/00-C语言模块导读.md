## 这个模块是什么

**王道 C 语言督学营**的逐字稿整理成的笔记。

它不是"从零学 C 语言"的教材，而是**为 408 和数据结构打地基**的一段准备课程，特点是：

| 特点           | 说明                             |
| ------------ | ------------------------------ |
| **重理解，轻背诵**  | 大量用类比（算盘、草稿纸、酒店房间）解释底层机制       |
| **边讲边动手**    | 每讲都配代码和调试器演示，不是纯理论             |
| **直接服务数据结构** | 内存、地址、字节这三件事，是后面学数组/指针/链表/树的前提 |

## 怎么用这个模块

### 推荐路径

```
第1章（动手为主）
   ↓ 装好 VS / CLion，跑通 hello world，会设断点
第2章（理解为王）
   ↓ 01 先建立"CPU + 存储器"的模型
   ↓ 02 打开 VS 跟着做一遍（必须动手）
   ↓ 03 弄懂每一行语法
   ↓ 04 搞懂内存和进制（最重要，要练）
第3章（书写规则，量小但全是坑）
   ↓ 01 空白字符：哪些可有可无、哪些不能少
   ↓ 02 注释：// 和 /* */，以及"屏蔽而不是删除"的习惯
   ↓ 03 标识符：三条命名规则 + 大小写敏感
第4章（数据类型，本章最重，11 讲）
   ↓ 01-03 常量、符号常量、变量：先搞清"数据对象"有哪些
   ↓ 04 数据类型全图：只需有印象
   ↓ 05-06 整型范围与溢出：必须会算、必须知道会绕回去
   ↓ 07 浮点数是近似值：不能比较相等
   ↓ 08 字符就是整数：'a'=97、'0'=48、大小写差 32
   ↓ 09 默认类型：1/2=0 和 (long long) 强制转换，最容易踩
第5章 …
```

## 和整体学习计划的关系

这份模块笔记对应[学习计划](../../学习计划.md)里的**第 1 阶段**（计算机基础 / 数据结构前的地基）。

**为什么先学 C 语言而不是直接上数据结构：**

| 学完这两章，你会          | 后面用在哪       |
| ----------------- | ----------- |
| 知道**变量在内存里的样子**   | 数组、指针、结构体   |
| 知道**地址是什么**       | 指针、链表       |
| 知道**1 字节 = 8 比特** | 位运算、内存对齐    |
| 会用**调试器看内存**      | 写数据结构时查指针错误 |

> 数据结构里最难的不是算法，是**指针出错却看不出错在哪**。调试器熟练 = 少熬很多夜。

### 怎么用视频（只讲这一次）

网盘播放器的「文稿」面板是**时间轴同步**的 —— **点哪句，视频就跳到哪一帧**。

```
① 打开网盘视频 → 右侧「文稿」面板
② Ctrl+F，粘贴你想找的任意一句话
③ 点中那一句 → 视频自动跳到对应画面
```

**笔记头部的 `值得回看` 一行**，标的就是"文字替代不了"的位置 —— 老师当场演算、调试器操作、
用记事本/Excel 做类比这些。**这类内容才值得回看视频，纯概念讲解看笔记就够。**

> ℹ️ 早期版本在每篇结尾放过「原文锚点」摘录表（17 篇 / 98 条），后来全删了 —— 因为**摘录等于把正文再念一遍**，

## 关于"逐字稿"

原始逐字稿在：

```

```

**它的三个作用**（也是这套笔记比普通网课笔记多出来的价值）：

1. **整理依据** —— 笔记内容都从这里来
2. **校对依据** —— AI 整理可能出错，**以老师原话为准**
3. **视频定位** —— 见下方"怎么找回视频"

> 所以每份笔记头部都记了**逐字稿的绝对路径和讲次**。发现笔记哪里讲得不清，直接回去看原文/看视频。

### 怎么找回视频

网盘里 **`.doc`（逐字稿）和 `.mp4`（视频）同名同序号**，所以命名规律只有一条：

> **把逐字稿文件名里的 `.doc` 换成 `.mp4`，就是视频文件名。**

```
网盘：01.27考研王道【C语言入门课程】/02.第二章/
  [5]--02_1_程序员视角当中的计算机.doc   ← 逐字稿
  [5]--02_1_程序员视角当中的计算机.mp4   ← 视频
```

每份笔记头部已经写好了**完整的网盘路径**，复制就能找到视频。
