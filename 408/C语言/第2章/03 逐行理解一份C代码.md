## 这一讲干什么

前两讲你看到了程序的**运行流程**，但对每一行语法细节还是不清楚。

这一讲把那份代码**当入口，一行一行拆开**——后面所有 C 语言语法，都从这份代码长出去。

```c
#include <stdio.h>

int main()
{
    int i = 1;
    i = i + 2;
    i = i + 3;
    i = i - 4;
    return 0;
}
```

---

## 第 1 行：`#include <stdio.h>`

**术语**：**预处理指令**（preprocessing directive）。

`#` 开头的都叫预处理指令。

**现在只需要知道**：你写的代码都得加上这一行（用到 `printf` 之类的时候）。

**详细内容**：代码生成过程中有一个步骤叫**预处理**，后面专门讲。

---

## 第 2 行：`int main() { ... }`

### 先搞清"定义"这个词

> **定义 = 把一个东西的所有信息都描述清楚。**

"函数定义"就是把一个函数的**方方面面、每个细节**都讲清楚。

### 函数的四个要素

```
int   main   ( )   { ... }
 ↑     ↑      ↑        ↑
返回值 名字   参数    函数体
```

| 要素 | 在这份代码里 | 说明 |
|---|---|---|
| **返回值** | `int` | 函数结束后交回给调用者的东西 |
| **名字** | `main` | 函数的标识 |
| **参数** | `( )` 空 | 调用这个函数时传进去的东西 |
| **函数体** | `{ ... }` | 函数真正执行的指令 |

### 名字：标识符 vs 关键字

| 术语 | 谁起的 | 例子 |
|---|---|---|
| **标识符** | **你自己** | `i`、`main`、`myFunc` |
| **关键字** | **C 语言语法规定** | `int`、`return`、`if`、`for` |

> 就像生了小孩，名字是你自己起的一样——函数名也是自己定的，这就是**标识符**。

### `main` 的特殊之处

**`main` 比较特殊：它是整个程序的入口。**

> 计算机要运行你的程序指令，**总是从 `main` 函数的第一行开始执行**。

### 参数和返回值 ↔ 数学函数

| 数学 | C 语言 |
|---|---|
| 自变量 x | **参数** |
| 因变量 y | **返回值** |

**但有一个关键区别：**

> 数学上 `y = f(x)` 是**一瞬间**完成的。
> C 语言里"给一个参数、得到一个返回值"要走**很长很长的路**——要执行很多很多条指令。
>
> **这些指令就放在函数体里。**

### `int` 是什么意思

`int` 是**关键字**，表示一种**整数类型**（一种数据类型）。

写在返回值位置，意思是：**`main` 函数要返回一个整数。**

### 空括号是什么意思

`( )` 里是空的 → **这个函数没有参数**，不需要传任何数据进去。

## 第 3 行：`int i = 1;`

### 先看分号

> **分号 = 一个表达式 / 一个句子的结束。**

写完一句就接分号。

### 这句话干了什么

拆开看：

```
int   i   =   1   ;
 ↑    ↑   ↑   ↑
类型  名字 赋值 初值
```

**完整含义**：定义一个**名字叫 `i`**、**类型是整数**的变量，创建时里面放**数值 1**。

### ⭐ 什么是「变量」

这是本章最重要的概念之一：

> **变量 = 在存储器里找了一块位置，并给它起了一个名字。**

对照第 2 讲的调试器：你在监视窗口看到的 `i`，就是**内存里某个字节的名字**。

**所以 `int i = 1;` 在内存层面做的事是：**

1. 在内存里划出一块位置
2. 这块位置以后就叫 `i`
3. 往里面写入数值 1

---

## 第 4~6 行：`i = i + 2;` 等

### ⚠️ 从右往左看

```
i = i + 2;
    └──┬──┘
    先算这个
```

**执行顺序**：

1. 先把 `i` 里面的数**取出来**（现在是 1）
2. **加上 2**（得到 3）
3. 把结果**赋值回去**，写回 `i` 那个位置

### ⚠️ `=` 是赋值，不是数学上的"等于"

| 数学里的 `=` | C 语言里的 `=` |
|---|---|
| 表示两边相等 | **表示"把右边的值放进左边"** |
| `i = i + 2` 在数学上无解 | 在 C 里完全合法：**取出 i，加 2，写回去** |

> 这个区别后面会反复遇到（比如 `if (a == b)` 用的是**两个**等号）。

### 后两句同理

| 语句 | 做的事 |
|---|---|
| `i = i + 3;` | 取出 i（3）→ 加 3 → 写回（6） |
| `i = i - 4;` | 取出 i（6）→ 减 4 → 写回（2） |

## 第 7 行：`return 0;`

### 作用

**把返回值交回给函数的调用者。**

`return 0;` = 返回一个整数 0。

### `main` 的返回值交给谁？

**交给操作系统。**

```
你启动程序
  ↓
操作系统创建一个进程
  ↓
操作系统调用 main 函数     ← 调用者就是操作系统
  ↓
main 执行完，return 0
  ↓
操作系统收到 0
```

### 0 有什么含义

| 返回值 | 含义 |
|---|---|
| **0** | 进程**顺利**结束 |
| **非 0** | 进程**没有顺利**结束（出错） |

> 这个约定在 Linux / Shell 脚本里到处都在用（`$?` 判断上一条命令是否成功）。

## 易错点

| 易错点 | 正确理解 |
|---|---|
| 以为 `i` 一开始就是 1 | **声明了不等于初始化了**，未初始化是垃圾值（见第 2 讲） |
| 把 `=` 当成"等于" | `=` 是**赋值**，从右往左看 |
| 以为函数名必须叫某个固定名字 | 名字是自己起的（**标识符**），只有 `main` 特殊 |
| 以为 `int main()` 的 `int` 没用 | 它规定了**返回值类型**，`return 0` 的 0 必须是整数 |
| 忘了分号 | 每条语句结尾都要 `;`（花括号不需要） |
| 用中文标点 | 括号、分号、引号**必须是英文半角** |
