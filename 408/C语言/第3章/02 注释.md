## 这一讲讲什么

**注释 = 只有人能读懂、编译器当作不存在的部分。**

效果上等于**把那段代码"挖走"**——不参与编译、不参与执行。C 语言只有两种注释写法，两个使用场景（解释代码、临时屏蔽代码）。

---

## 一、效果验证：注释掉一行，值就不一样了

老师的演示很有说服力，值得记下来。

**原始代码**（第 3~6 行）：

```c
int i = 1;        // 第 3 行
i = i + 2;        // 第 4 行  ← 在这行前面加 //
i = i + 3;        // 第 5 行
i = i - 4;        // 第 6 行
```

**操作**：在第 4 行前面加两个正斜杠 `//` → 这一行变成**绿色**。

**调试观察**（断点在第 3 行，按 F10）：

| 步骤 | 预期（不加注释） | 实际（加了注释） |
|---|---|---|
| 执行完第 3 行 | `i = 1` | `i = 1` |
| 再按 F10 | 走到第 4 行，`i = 3` | **直接跳到第 5 行** |
| 第 5 行执行完 | — | **`i = 4`**（1 + 3，跳过了 +2） |

> **结论：`//` 之后的这一行代码，等于被删掉了。**
> 注意结果变成 **4** 而不是 3 —— 这正是"少执行了一次 +2"的证据。

## 二、两种注释

| 类型 | 写法 | 生效范围 | 例子 |
|---|---|---|---|
| **单行注释** | `//` | 本行 `//` **之后**的内容 | `i = i + 3;  // 这里是注释` |
| **多行注释** | `/*` … `*/` | `/*` 和 `*/` **中间全部** | `/* 第6行 第7行 */` |

### 2.1 单行注释只对"后面"生效

```c
i = i + 3;    // 这句代码有效，后面的文字才是注释
// i = i + 2;    整行都被注释
```

> **`//` 前面的代码照常编译**，只有它后面的内容是注释。

### 2.2 多行注释可以跨行

```c
/*
i = i + 2;
i = i + 3;
*/
```

中间两行都被注释掉，**即使它们前面没有 `//`**。

> 编辑器里也会相应变色（绿色）——但**变色只是编辑器的着色，不是语法的一部分**，别拿颜色当判据。

## 三、两个使用场景

### 3.1 解释代码

说明**变量的作用**、**运算的作用**，给读代码的人（包括三个月后的自己）看。

```c
int i = 1;          // i 表示当前累计值
i = i + 2;          // 累加 2
```

### 3.2 临时屏蔽代码（**这条更实用**）

代码可能有问题时，**不要直接删掉**，改成注释：

```c
i = i + 2;
// i = i + 3;      ← 怀疑这行有问题，先注释
i = i - 4;
```

> **为什么注释而不是删除**：万一那行没问题，**改回来就行**；删了就得重打。

**这是调试的基本习惯**：用注释做"可逆的删除"。

## 四、补充：注释不能嵌套（老师没讲，但迟早踩）

```c
/* 外层 /* 内层 */ 这里已经结束了 */
```

**多行注释遇到第一个 `*/` 就结束**，所以**不能嵌套**。

后果：想注释掉一大段（里面本来就有 `/* */`）时，会被**提前截断**，后面的代码就跑起来了。

**三种应对**：

| 办法 | 说明 |
|---|---|
| 用 `//` 一行行注释 | 最稳，编辑器一般有快捷键 |
| 用 `#if 0 … #endif` | 预处理屏蔽，真正的"整段关掉"（后面会学） |
| 避免在被注释的段落里写块注释 | 习惯问题 |

## 易错点

| 易错点 | 正确理解 |
|---|---|
| 以为 `//` 会注释掉整行 | 只注释**它后面**的部分，前面代码有效 |
| 拿编辑器变色当语法判据 | 颜色是编辑器行为，**语法只看编译结果** |
| 用 `/* */` 嵌套 | **不能嵌套**，遇到第一个 `*/` 就结束 |
| 调试时直接删代码 | 应该**注释**，可逆 |
| 注释写"是什么" | 好注释写**为什么**（"为什么加 2"，不是"加 2"） |

> **注释 = 人能看懂、编译器当作不存在（等于把那段代码挖走）。**
