## 这一讲讲什么

**关键字**是 C 语言**规定好的**词，**标识符**是**你自己起的**名字。两者不能重名，而且 C 语言**大小写敏感**。

标识符只有**三条**命名规则，这一讲把每条都配了正反例。

---

## 一、关键字：语言规定的，不是你选的

> **关键字由 C 语言语法规定，有固定的含义和用途。**

| 项目 | 说明 |
|---|---|
| 谁定的 | **C 语言语法**（不是使用者） |
| 特点 | 有**固定含义和用途**，不能拿来做别的事 |
| 数量 | **32 个**（C89 / ANSI C 的数目） |
| 例子 | `int`（表示整数类型）、`return`（表示函数返回） |

> **补充**：32 个是 C89 的数字。C99 之后又加了几个（`inline`、`restrict` 等），C11 还加了 `_Atomic`、`_Generic` 等。
> **不用背**——老师也说了："用得上的后面都会讲，用不上的不用考虑。"

---

## 二、C 语言大小写敏感（这一讲的第一个坑）

> **小写字母和大写字母不能看成是一样的。**

```
int      → 是关键字 ✅
Int      → 不是关键字 ❌（I 大写了）
```

**改一个字母会怎样**：把 `int` 的 `i` 改成大写 `I` → 编辑器**冒红线** → 编译 → 输出窗口报：

```
'int' 是未声明的标识符
```

**为什么这个报错信息值得记**：它说明编译器把 `Int` 当成"**一个你想用但没定义过的名字**"——
也就是说，**它从关键字降级成了标识符**。

| 写法 | 身份 |
|---|---|
| `int` | 关键字（语法成分） |
| `Int` | 标识符（一个你还定义的名字，所以报"未声明"） |

---

## 三、标识符：用来起名字

> **标识符 = 用来给变量、函数起名字的东西。**

`int i = 1;` 里的 `i` 是标识符；`int main()` 里的 `main` 也是标识符。

### 3.1 三条命名规则

| # | 规则 |
|---|---|
| **1** | **不能和关键字重复**（大小写敏感，`Int` 可以） |
| **2** | **只能包含：数字、字母、下划线 `_`** |
| **3** | **开头不能是数字** |

### 3.2 逐条对应正反例

**规则 1：不能和关键字重名**

```c
int int;     // ❌ int 是关键字
int Int;     // ✅ 大小写不同，Int 是普通标识符
```

**规则 2：只能由数字 / 字母 / 下划线组成**

```c
int x3y;     // ✅ 字母数字组合
int xy_1;    // ✅ 带下划线
int x-y;     // ❌ 减号不在允许的字符集里
```

**规则 3：开头不能是数字**

```c
int 3xy;     // ❌ 数字开头
int xy3;     // ✅ 数字在中间/末尾可以
```

### 3.3 判定总表（老师课上的四个例子 + 扩展）

| 写法 | 合法 | 原因 |
|---|---|---|
| `int` | ❌ | 和关键字重复 |
| `Int` | ✅ | 大小写不同，不算关键字 |
| `3xy` | ❌ | **数字开头** |
| `xy3` | ✅ | 数字不在开头 |
| `x3y` | ✅ | 同上 |
| `x` | ✅ | 单个字母 |
| `_` | ✅ | 单个下划线（**但见下方补充**） |
| `3` | ❌ | 数字开头 |

> **补充（重要）**：`_` 开头的标识符**语法合法**，但 C 标准把 `_` + 大写字母、以及 `__` 开头的名字**保留给编译器和标准库**。
> 自己写代码**不要用**这类名字——虽然能编译，但可能和系统内部的名字撞车。

---

## 四、怎么快速验证一个名字合不合法

| 方法 | 操作 | 看什么 |
|---|---|---|
| **最快** | 直接敲进代码里 | 编辑器**冒不冒红线** |
| **最准** | 右键 `main.cpp` → 编译 | **输出窗口**的报错 |

> 结合第 1 讲：**编译后看输出窗口，不是错误列表窗口。**

---

## 易错点

| 易错点 | 正确理解 |
|---|---|
| 以为 `Int` 也是关键字 | **大小写敏感**，`Int` 是普通标识符 |
| 看到"未声明的标识符"以为是缺头文件 | 先检查是不是**大小写写错**了关键字 |
| 以为标识符能随便起 | 三条规则：不撞关键字、只用数字字母下划线、不以数字开头 |
| 用 `_` 或 `__` 开头 | 语法合法，但**保留给实现**，自己别用 |
| 以为关键字只有课上见过的那几个 | 共 **32 个**（C89），其余用到再记 |

## 一句话记忆

> **关键字是语言定的（32 个），标识符是你起的名字。**
> **三条规则：不撞关键字、只用数字/字母/下划线、不以数字开头。**
> **C 语言大小写敏感——`int` 是关键字，`Int` 就是个陌生名字。**
