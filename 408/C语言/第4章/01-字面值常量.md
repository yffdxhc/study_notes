## 这一讲讲什么

C 语言操作的数据对象**只有两类：常量和变量**。这一讲讲前者。

**字面值常量 = 直接写在代码里的值**（`1234`、`3.14`、`'a'`、`"hello"`）。它一写出来就看得懂，但**不可修改**——这条性质会被编译器强制检查。

最后引出它的致命缺点：**魔法数**。

---

## 一、总纲：数据对象只有两类

| 类别 | 能否修改 | 细分 |
|---|---|---|
| **常量** | **不可修改** | ① 字面值常量 ② 符号常量 |
| **变量** | 可修改 | （下一讲讲） |

> **"常"字就是"不可修改"的意思。**

---

## 二、字面值常量：四种

**特点：一写出来就知道它的含义。**

| # | 类型 | 写法 | 例子 |
|---|---|---|---|
| 1 | **整型** | 若干个数字连着写 | `1234` |
| 2 | **浮点型** | 带小数点。**C 语言里不叫"小数"，叫"浮点数"** | `3.14` |
| 3 | **字符型** | 一对**英文单引号**，中间**一个**字符 | `'a'` `'1'` `'?'` |
| 4 | **字符串型** | 一对**双引号**，中间可以多个字符 | `"hello world"` |

### 2.1 两个引号的区分（必须记牢）

| 引号 | 类型 | 里面能放几个字符 |
|---|---|---|
| **单引号** `'…'` | 字符 | **恰好一个** |
| **双引号** `"…"` | 字符串 | 零个或多个 |

> **⚠️ 必须是英文引号**。中文引号 `‘’` `“”` 编译器不认。

---

## 三、验证：常量确实不可修改

老师在代码里分别对这四种常量做赋值：

```c
1234 = 1235;              // 整型
3.14 = 3.14;              // 浮点型（连原值覆盖都不行）
'a' = 'c';                // 字符型
"hello" = "world";        // 字符串型
```

**四种全部报同一个错**：

```
等号的左操作数必须为左值
```

**"左值"（lvalue）= 可以放在赋值号左边、能被修改的东西**。

> 常量不是左值 → 不能放等号左边 → **编译期就被挡住，不是运行时才出错**。

## 四、常量能用来干什么：算个圆面积

```c
printf("r=%d, a=%d", 3, 3 * 3 * 3);
// 输出：r=3, a=27
```

两个新东西：

| 东西 | 说明 |
|---|---|
| `printf` | 打印函数（后面详讲） |
| `%d` | **占位符**：先占个位置，运行时用后面的表达式结果顶替 |

**执行过程**：第一个 `%d` ← `3`（半径）；第二个 `%d` ← `3*3*3` 的结果 `27`（面积）。

> 用了 `printf` 打印到控制台之后，**不需要打断点也能看结果**。

## 五、致命缺点：魔法数

### 5.1 需求变更暴露的问题

现在要把半径从 3 改成 4。**直觉做法**：把代码里所有的 `3` 都改成 `4`。

**结果错了**：

```c
// 原来
printf("r=%d, a=%d", 3, 3 * 3 * 3);   // 半径3、π3 → 27
// 无脑全改
printf("r=%d, a=%d", 4, 4 * 4 * 4);   // ❌ 64，错了
// 正确
printf("r=%d, a=%d", 4, 3 * 4 * 4);   // ✅ 48
```

**为什么**：代码里的 `3` **并不都表示半径**——`π` 也是 3。

> **看到这个孤零零的 `3`，你没法判断它是半径还是圆周率。**

### 5.2 这就是"魔法数"

| 项目 | 说明 |
|---|---|
| **英文** | magic number |
| **定义** | 代码里直接写死的数字，读代码的人**看不出它代表什么** |
| **后果** | 改代码要通读上下文；容易误改；增加工作量 |
| **对策** | 用**符号常量**给它起名字 |

---

## 易错点

| 易错点 | 正确理解 |
|---|---|
| 把 `'a'` 和 `"a"` 混用 | 单引号 = 字符，双引号 = 字符串，**类型不同** |
| 用中文引号 | 必须**英文**引号 |
| 以为常量赋错值是运行时错误 | **编译期就报错**（左操作数必须为左值） |
| 把 C 语言的"小数"叫小数 | 叫**浮点数** |
| 改需求时无脑替换数字 | 这就是**魔法数**陷阱，应该改用符号常量 |

> **数据对象两类：常量（不可改）+ 变量（可改）。**
> **字面值常量四种：整数 `1234`、浮点 `3.14`、字符 `'a'`（单引号，一个）、字符串 `"abc"`（双引号，多个）。**
> **它的病叫魔法数——数字看不出含义；药是符号常量。**
