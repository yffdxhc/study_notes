## 这一讲讲什么

**变量 = 一片有名字的内存区域。** 一句话把它的本质说完了。

这句话里藏着两个要素：**名字**（怎么访问）和**数据类型**（多大、怎么解释）。这一讲把这两点拆开讲，顺带说清一个高频混淆：**初始化 ≠ 赋值**。

---

## 一、变量到底是什么

### 1.1 从"变"字开始

| 对象 | 能否修改 |
|---|---|
| 字面值常量 | ❌ |
| 符号常量 | ❌ |
| **变量** | ✅ |

**但"变"的是什么？** 变的**不是数据代表的意义**，而是**那片内存区域里放的内容**。

### 1.2 定义

> **变量是「一片内存区域」——一片可以放数据的内存区域，并且有名字与之关联。**

```
变量 = 内存区域（能放数据） + 名字（能找到它）
```

---

## 二、变量的两个要素

> **要在代码里把一个变量描述清楚，只需要两样东西：名字 + 数据类型。**

| 要素 | 它决定什么 |
|---|---|
| **名字** | 你怎么找到这片内存 |
| **数据类型** | ① 这片内存**多大**（几个字节）<br>② 里面的 0/1 序列**怎么解释**（编码规则） |

### 2.1 为什么是"这两个"

回顾内存模型（第 2 章）：

```
内存 = 大酒店
字节 = 房间
地址 = 房间号
```

**要"开一间房"并"能用它"**，需要三个信息：

| 问题 | 由谁回答 |
|---|---|
| 房间有多大？ | **数据类型** |
| 房间里的东西怎么理解？ | **数据类型** |
| 怎么叫这间房？ | **名字** |

> 1 字节 = 8 比特；里面是 0/1 序列，这叫**机器数**；人类理解的是**真值**。
> **机器数 ↔ 真值 的映射规则 = 编码规则 = 由数据类型决定。**

### 2.2 名字的要求

就一条：**符合标识符规范**（第 3 章讲过）：

- 以字母或下划线开头
- 后续可为数字 / 字母 / 下划线
- 不能和关键字重名
- **区分大小写**

## 三、定义变量

```c
int i;              // 类型 + 名字
double d1, d2;      // 同类型可一行定义多个，用逗号隔开
```

**顺序固定：先写数据类型，再写变量名。**

### 3.1 用 `sizeof` 看它占多大

```c
printf("sizeof i = %d\n", sizeof i);
```

| 关于 `sizeof` | 说明 |
|---|---|
| 是什么 | **运算符**（不是函数） |
| 作用 | 求一个类型 / 一个变量在内存中占的**字节数** |
| 后面接什么 | **变量名**（`sizeof i`）或**类型名**（`sizeof(double)`）都可以 |

**实测结果**：

| 表达式 | 结果 |
|---|---|
| `sizeof i`（i 是 int） | **4** 字节 |
| `sizeof d1` / `sizeof d2` | **8** 字节 |
| `sizeof(double)` | **8** 字节 |

> **结论：数据类型决定变量占多少字节。** 同一类型的变量，大小必然相同。

## 四、初始化 vs 赋值（这一讲最该记住的点）

### 4.1 两个概念

| 概念 | 定义 |
|---|---|
| **初始化** | **创建变量的同时**给它一个初始值 |
| **赋值** | 变量已存在，**用新值取代原来内存里的内容** |

### 4.2 它们用**同一个**运算符

```c
int i = 3;      // 第 1 个 = ：初始化（在定义语句里）
i = 4;          // 第 2 个 = ：赋值
i = i + 1;      // 第 3 个 = ：赋值
```

> **三行都有 `=`，但含义不同。**

**区分规则**：

| `=` 的位置 | 叫什么 |
|---|---|
| **在定义语句里**（和类型/名字同时出现） | **初始化** |
| **在其他位置** | **赋值** |

> **C 语言里同一个符号、同一个运算符，在不同位置可能有不同的含义。**
> 这个认识对后面学 `*`（乘 / 解引用）、`&`（取地址 / 位与）同样关键。

### 4.3 `i = i + 1` 怎么读

> **一定要「先右后左」。**

```
① 先算右边：i + 1  →  得到一个临时的结果
② 再写回左边：用这个结果取代 i 原来的内容
```

**调试实测**：

| 语句 | 执行后 `i` |
|---|---|
| `int i = 3;` | 3 |
| `i = 4;` | 4 |
| `i = i + 1;`（先算 4+1=5，再写回） | **5** |

---

## 易错点

| 易错点 | 正确理解 |
|---|---|
| 把 `i = i + 1` 当数学等式 | 它是**"算出新值再覆盖"**，不是"i 等于 i+1" |
| 把初始化都说成赋值 | **定义语句里的 `=` 是初始化**，其余是赋值 |
| 以为变量只由名字决定 | 还有**数据类型**，它决定大小和编码规则 |
| 把 `sizeof` 当函数 | 它是**运算符**，`sizeof x` 不需要括号（但 `sizeof(int)` 需要） |
| 忘了变量名要符合标识符规范 | 和标识符同一套规则 |

## 一句话记忆

> **变量 = 一片有名字的内存区域。两个要素：名字（怎么找）+ 数据类型（多大、怎么解释）。**
> **`sizeof` 是运算符，能求类型或变量的字节数。**
> **`=` 在定义语句里是初始化、在别处是赋值；`i = i + 1` 先算右边再写回左边。**
