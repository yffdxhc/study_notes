## 这一讲讲什么

**一张地图。** 把基本数据类型摆出来，讲清它们之间怎么分。

这一讲**不要求记细节**——老师说得很明确：现阶段"有个基本印象、能把代码写出来"就够了，编码规则留到计组再深化。

## 一、总图

```
基本数据类型
│
├── 整数类型
│   ├── 有符号整数（能表示 负数 / 0 / 正数）
│   │     char → short → int → long → long long
│   │     （按占用内存从小到大）
│   │
│   └── 无符号整数（只能表示 0 / 正数）
│         在每种类型前加 unsigned：
│         unsigned char / unsigned short / unsigned int
│         / unsigned long / unsigned long long
│
└── 浮点类型
    ├── 单精度：float
    └── 双精度：double
```

> 现阶段只学**基本数据类型**；后面还有**复合数据类型**。

## 二、两种切分维度

### 2.1 按"整数还是带小数"

| 类别 | 判据 |
|---|---|
| **整数类型** | 是整数（没有小数点） |
| **浮点类型** | 带小数点的数（C 里叫浮点数，不叫小数） |

### 2.2 整数再按"能不能表示负数"

| 类别 | 能表示 | 前缀 |
|---|---|---|
| **有符号整数** | 负数、0、正数 | 无前缀 |
| **无符号整数** | **只有 0 和正数** | `unsigned` |

**有符号整数按占内存从小到大**：

```
char  <  short  <  int  <  long  <  long long
```

**无符号整数** = 在上面的每种类型前加 `unsigned`：

```c
unsigned char   unsigned short   unsigned int   unsigned long   unsigned long long
```

### 2.3 浮点数只有两种

| 类型 | 名称 |
|---|---|
| `float` | **单精度**浮点数 |
| `double` | **双精度**浮点数 |

## 三、一个"坑爹"的知识点：字符的本质是整数

> **`char` 既是最小的整数类型，又是字符类型。**

| 身份 | 说明 |
|---|---|
| 作为**整数**类型 | 占 1 字节，能存 -128 ~ 127 |
| 作为**字符**类型 | 存 `'a'` 这样的字符 |

**为什么可以两副面孔**：因为**字符在计算机里本来就是用整数（编码）表示的**——这一讲只点出来，后面「字符和 ASCII 编码」那一讲会展开。

## 四、这门课会把数据类型学两遍

| 阶段 | 学到什么程度 |
|---|---|
| **现在（C 语言课）** | 知道有哪些类型、怎么用、怎么写代码、怎么看懂 |
| **后面（计算机组成原理）** | 深入到每种类型的**编码规则**（机器数怎么表示真值） |

> **所以现在不用死磕底层**，把"有哪些、怎么用"吃透就行。

---

## 易错点

| 易错点 | 正确理解 |
|---|---|
| 以为 `char` 只是"字符类型" | 它**同时是最小的整数类型** |
| 以为无符号仅仅是"不带符号" | 是**不能表示负数**，范围变成 0 起 |
| 把 `unsigned` 记成前缀以外的东西 | 它就是加在类型名**前面**的修饰 |
| 以为浮点数有 int 那种大小分级 | 浮点只有 **float / double** 两种 |
| 现在就想把编码规则学透 | 那是计组的内容，**现在只需有印象** |

## 一句话记忆

> **基本数据类型 = 整数（有符号 char/short/int/long/long long；无符号加 `unsigned`）+ 浮点（float / double）。**
> **`char` 最特殊：既是最小整数，又是字符类型——因为字符本质就是整数。**
> **现在只要有印象，编码规则留到计组。**
