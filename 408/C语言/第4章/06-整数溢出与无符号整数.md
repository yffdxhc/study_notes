## 这一讲讲什么

**整数类型都有范围，超了就"绕回去"** —— 这叫**溢出**。

这一讲分两半验证同一个结论：

| 类型 | 最大正数 + 1 | 结果 |
|---|---|---|
| **有符号** `int` | `0x7FFFFFFF`（≈21 亿） | 变成**负数** |
| **无符号** `unsigned int` | `0xFFFFFFFF`（≈42 亿） | 变成 **0** |

> **结论：不管什么数据类型，都有范围，都会溢出。**

---

## 一、溢出现象：最大的正数 + 1 变负数

```c
int i = 0x7FFFFFFF;     // 2^31 - 1，int 能表示的最大正数（21 亿多）
i = i + 1;              // 只是个 +1
printf("i = %d\n", i);  // 输出的是个负数！
```

### 为什么 `0x7FFFFFFF` 是最大正数

```
7     f     f     f     f     f     f     f
0111 1111 1111 1111 1111 1111 1111 1111
 ↑
 最高位是 0（表示正数），其余 31 位全是 1 → 正好是 2^31 - 1
```

> 最高位是**符号位**：0 = 正、1 = 负。所以最大正数就是"符号位 0 + 其余全 1"。

---

## 二、溢出的定义（两个方向）

| 情况 | 表现 |
|---|---|
| **很大的正数 + 一个数**，超过上限 | 结果变成**负数** |
| **很小的负数 − 一个数**，低于下限 | 结果变成**正数** |

> **两种都叫溢出。** 判据是"结果跑出了这个类型能表示的范围"。

**为什么是这样**，这一讲先不讲（要留到**计组**）。现在只需要建立直觉：

> **超过范围之后的数值是不可信的——它会莫名其妙变成符号相反的数。**

---

## 三、无符号整数

### 3.1 怎么来的

在**每一种**有符号整数类型前加 `unsigned`：

```c
unsigned char   unsigned short   unsigned int   unsigned long   unsigned long long
```

### 3.2 和对应的有符号类型**一样大**

| 类型 | 字节数（VS x64） |
|---|---|
| `unsigned char` | 1 |
| `unsigned short` | 2 |
| `unsigned int` | 4 |
| `unsigned long` | 4 |
| `unsigned long long` | 8 |

> 大小相同，但**省掉了负数那一半**，全给了正数。

### 3.3 范围：`0 ~ 2^n − 1`

| 类型 | n | 范围 |
|---|---|---|
| `unsigned char` | 8 | **0 ~ 255** |
| `unsigned short` | 16 | **0 ~ 65535**（6 万 5 千多） |
| `unsigned int` / `unsigned long` | 32 | **0 ~ 4294967295**（42 亿多） |
| `unsigned long long` | 64 | 0 ~ 2^64 − 1 |

### 3.4 有符号 vs 无符号（同一比特数，范围搬家）

| 比特 n | 有符号范围 | 无符号范围 |
|---|---|---|
| 8 | −128 ~ 127 | **0 ~ 255** |
| 16 | −32768 ~ 32767 | **0 ~ 65535** |
| 32 | ±21 亿 | **0 ~ 42 亿** |

> **同一个 32 比特，有符号是 ±21 亿，无符号是 0~42 亿。**
> 有符号的一半给了负数；无符号把这半也拿来当正数用。

---

## 四、打印无符号：用 `%u`，不是 `%d`

```c
unsigned int u = 0xFFFFFFFF;
printf("u = %u\n", u);    // ✅ 用 %u
printf("u = %d\n", u);    // ❌ %d 只用于有符号整数
```

| 占位符 | 用于 |
|---|---|
| `%d` | **有符号**十进制整数 |
| `%u` | **无符号**十进制整数 |
| `%lld` | long long（下一讲） |

> **占位符和类型要匹配**，不匹配打印出来可能是错的。

---

## 五、无符号也会溢出：最大的数 + 1 = 0

```c
unsigned int u = 0xFFFFFFFF;   // 42 亿多，无符号的最大值
u = u + 1;
printf("u = %u\n", u);         // 输出 0 ！
```

**为什么是 0**：全 1 再加 1 → 全部进位 → 32 位全变 0（进位被丢掉）。

| 类型 | 最大 + 1 变成 |
|---|---|
| 有符号 `int` | **负数** |
| 无符号 `unsigned` | **0** |

> 形式不同，本质相同：**都跑出了范围，结果不可信。**

---

## 六、推广结论

> **无论什么数据类型，都是有范围的，都会发生溢出。**

所以后面写代码时，遇到"算出来的值很怪"（比如很大的乘积变成 0），**第一反应应该是查类型范围**，而不是怀疑编译器。

---

## 易错点

| 易错点 | 正确理解 |
|---|---|
| 以为只有无符号会溢出 | **有符号也会**，只是表现形式不同（变负数） |
| 用 `%d` 打印 `unsigned` | 应该用 **`%u`** |
| 以为 `unsigned` 只是"不能为负" | 它的**上限也变大了一倍**（付掉的那半给了上限） |
| 以为溢出会报错 | **不会报错**，静默算出错误的值 |
| 想把溢出原理现在搞懂 | 那是**计组**的内容，现在只要知道"会出错" |

## 一句话记忆

> **有符号溢出：最大正数 + 1 → 负数；无符号溢出：最大数 + 1 → 0。**
> **无符号 = 加 `unsigned` 前缀，大小不变、范围变成 `0 ~ 2^n−1`，打印用 `%u`。**
> **所有类型都有范围，超了不报错，只是结果不可信。**
