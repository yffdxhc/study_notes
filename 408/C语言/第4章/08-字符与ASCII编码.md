## 一、字符类型与字符常量

| 项目 | 说明 |
|---|---|
| 类型名 | `char`（**同时是最小的整数类型**） |
| 字符常量 | 一对**单引号**，里面放**一个**字符 |
| 打印占位符 | **`%c`**（不是 `%d` / `%u` / `%f`） |

```c
char ch = 'a';
printf("ch = %c\n", ch);     // ch = a
```

**能放什么**：字母、数字、标点符号（屏幕上能显示的一个字符都行）。

### 1.1 单引号里只能一个字符

```c
char ch = 'ab';     // ❌ 报错：放两个它就不知道是什么了
```

### 1.2 字符类型只能显示"一位"数字

```c
char c = '5';       // 显示 5
// 但你不能用它显示 12345 —— 那要用 %d 打印整数
```

> **`'5'` 是一个字符；`5` 是一个整数。** 两者类型不同。

## 二、转义字符：写出来的 ≠ 它代表的

**为什么要它**：换行、回车这些字符**没法直接打出来**（你总不能在一对单引号里真敲个换行）。

```c
char ch = '
';         // ❌ 语法错误
```

**于是有了转义字符**：

> **转义字符 = 写在代码里的样子，和它代表的含义不一样。**

`\n` 你在代码里看到的是"反斜杠 + n"两个符号，但它们**合在一起**表示**一个换行字符**。

### 2.1 常用的五个

| 转义 | 名称 | 效果 | 例子 |
|---|---|---|---|
| `\n` | **换行**（newline） | 光标移到**下一行行首** | `"ABC\nxyz"` → ABC 和 xyz 分两行 |
| `\r` | **回车**（return） | 光标移到**本行最左** | `"ABC\rxyz"` → 显示 `xyz` |
| `\b` | **退格**（backspace） | 光标**退一格** | `"ABC\bxyz"` → `abxyz` |
| `\t` | **制表符**（tab） | 相当于按 Tab，跳到下一列 | `"ABC\txyz"` → 两列 |
| `\\` | **反斜杠** | 显示一个 `\` | 必须**连打两个** |

### 2.2 逐个好理解

**`\r`（回车）**：想象记事本里的光标。

```
打印 ABC      光标在 → 末尾
\r            光标回到 ← 最左边
打印 xyz      x 覆盖 A、y 覆盖 B、z 覆盖 C
最终显示：xyz
```

> **回车不换行，它只是把光标拉回行首**——后面的字符会**覆盖**前面的。

**`\b`（退格）**：和回车类似，但**只退一格**。

```
打印 ABC      位置：A B C |（光标在 C 后）
\b            光标退到 C 的位置
打印 xyz      用 x 覆盖 C，再往后写 y z
最终显示：abxyz
```

**`\t`（制表符）**：把 `ABC\txyz` 复制到 Excel 里，会发现它们占**两列**。

**`\\`（反斜杠）**：因为 `\` 是转义引导符，**单独一个 `\` 显示不出来**，必须写两个。

## 三、字符的本质：`'a'` 就是 `97`

### 3.1 怎么发现

```c
char ch = 'a';
// 把鼠标悬停在 'a' 上 → 显示 97
```

> **`'a'` 和 `97` 是完全等价的。**

### 3.2 双向验证

```c
char ch1 = 'a';
printf("%d\n", ch1);       // 97    ← 用整数方式看
printf("%c\n", ch1);       // a     ← 用字符方式看

char ch2 = 97;
printf("%c\n", ch2);       // a     ← 存 97，按字符解释就是 a
```

### 3.3 关键结论

> **内存里存的永远是那个整数（97）。**
> **你看到的是 `97` 还是 `a`，完全取决于你用什么占位符去解释它。**

| 占位符 | 解释方式 | 输出 |
|---|---|---|
| `%d` | 按十进制整数 | `97` |
| `%c` | 按字符 | `a` |

> **这就是"字符的本质是整数"的准确含义：不是"字符可以转成整数"，而是"字符就是整数，只是解释方式不同"。**

## 四、ASCII 编码表

### 4.1 它是什么

**一张"数值 ↔ 字符"的对应表**，由美国人制定，把他们常见的符号（大小写字母、数字、标点）全部用数值对应起来。

| 项目 | 说明 |
|---|---|
| 名字念法 | /ˈæski/（"**阿斯克**"），不是按字母念 "S-K" |
| 总数 | **128** 种（数值 0 ~ 127） |
| 占几位 | **7 个比特**（第 8 位留作别的用途） |

### 4.2 必须记住的几个值

| 数值 | 字符 | 说明 |
|---|---|---|
| **0** | NUL | 空字符 |
| **10** | LF | 换行（就是 `\n`） |
| **48 ~ 57** | `'0'` ~ `'9'` | 字符数字 |
| **65 ~ 90** | `'A'` ~ `'Z'` | 大写字母 |
| **97 ~ 122** | `'a'` ~ `'z'` | 小写字母 |

> 老师只讲了 0、10、48–57、65–90（实为 A–Z）、97（a）。**A–Z 是 65~90、a–z 是 97~122** 这一条是按"相差 32"推出来的，与表中数值一致。

## 五、三条必须带走的规律

### 5.1 ⚠️ `'0'` 不等于 0

```c
char c = '0';        // 这个字符的值是 48，不是 0！
printf("%d\n", c);   // 输出 48
```

> **屏幕上显示的字符 `0`，和数值 `0` 完全是两回事。** 这是新手最容易混的一处。

### 5.2 字符做差值 = 整数值做差值

```c
'3' - '1'  ==  2      // 因为 51 - 49 = 2
```

> **两个字符相减，等于它们对应的整数相减。** 这个性质后面处理字符串会很有用。

### 5.3 大小写相差 32

```c
'a' - 32  ==  'A'     // 97 - 32 = 65
'X' + 32  ==  'x'     // 88 + 32 = 120
```

> **小写字母的数值 = 大写字母的数值 + 32。**

## 易错点

| 易错点 | 正确理解 |
|---|---|
| 把 `'0'` 当成 0 | 它是 **48** |
| 单引号里放两个字符 | **报错**，只能一个 |
| 用 `%d` 打印字符想看字符 | 用 **`%c`** |
| 直接在一对单引号里敲换行 | 语法错误，要用 **`\n`** |
| 以为回车会换行 | `\r` 只回行首，**`\n` 才换行** |
| 想单独显示一个反斜杠 | 必须写 `\\` |
| 以为"字符转整数"是一次转换 | 字符**本来就是**整数，只是解释方式不同 |

## 一句话记忆

> **`char` 是最小的整数类型，字符的底层就是整数：`'a'` = 97、`'0'` = 48、`'A'` = 65，大小写差 32。**
> **看到 97 还是 a，取决于用 `%d` 还是 `%c` 去解释。**
> **转义字符：`\n` 换行、`\r` 回车（回行首）、`\b` 退格、`\t` 制表、`\\` 反斜杠。**
