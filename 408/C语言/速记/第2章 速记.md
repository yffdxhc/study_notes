> 本章 4 讲：算盘模型 → 调试器验证 → 逐行语法 → 内存与进制。

## 一、程序员眼中的计算机

- **模型 = CPU + 存储器 + 时钟**。这三样是"计算机是什么"的完整答案。
- **抽象**：把复杂的、没用的细节隐藏起来，提炼出真正有用的核心要素。（这就是"程序员视角"）
- 类比：**算盘 = CPU**（负责算）、**草稿纸 = 存储器**（记中间结果）、**人 = 控制器**。
- **草稿纸上不只有数据，还有指令** —— 存储器既存数据也存"下一步做什么"。
- **CPU 一个周期三件事**：**取指 → 执行（算）→ 写回**。
- **时钟**：滴答滴答不停地走，靠它**重复**执行上面的循环。

## 二、调试器：把上面的模型验证一遍

- **调试 = 编译 + 运行**（完整链路：预处理 → 编译 → 汇编 → 链接）。
- **断点**：程序停在**这一行执行之前**，不是执行完。
- **`F10` 步过**：不进入函数内部，函数照常执行完。**`F11` 步入**：进函数里一行行看。
- 调试时能看：变量值、`&变量`（地址）、内存窗口。
- **局部变量未初始化有"垃圾值"**（课上看到的 696 就是内存残留）——所以调试时别被它吓到。

## 三、逐行读代码

- **函数的四要素**：返回值类型 + 函数名 + 参数列表 + 函数体。
- `int main()` —— `main` 是**入口**，`int` 是返回类型。
- **变量 = 内存里的一块地 + 一个名字**（第 4 章会展开成"名字 + 数据类型"）。
- `=` 是**赋值**，不是数学等号：**先算右边，再写回左边**。
- `i = i + 2` 读作：取 `i` 的旧值 → 加 2 → 覆盖 `i` 原来的内容。
- `return 0` —— 返回给操作系统，**0 = 正常结束**。
- 语句以 `;` 结尾。

## 四、内存与进制（本章最该练的）

- **信息 = 对不确定性的消除**（香农）。不确定越大，信息量越大。
- **比特（bit）= 一位 0 或 1** —— 这是信息的最小单位。
- **1 字节 = 8 比特**。内存的最小单位是**字节**。
- **机器数 vs 真值**：内存里存的是 0/1 序列（机器数），人理解的是数值（真值），两者靠**编码规则**对应。
- **进制转换（除二取余法）**：不断除以 2，**余数倒着写**。
- **地址宽度决定内存上限**：32 位地址 → 最多 2^32 个字节 = **4GB**。

## 五、这一章的三条主线

```
① 建模型    CPU + 存储器 + 时钟，以及"取指 → 执行 → 写回"
② 会验证    用调试器亲眼看变量、地址、内存
③ 懂底层    比特 / 字节 / 机器数 / 进制 / 地址
```
