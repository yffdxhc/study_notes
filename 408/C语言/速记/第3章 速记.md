# 第3章 速记

> **一章压成一页，5 分钟过一遍。** 看不懂的条目，去翻对应笔记正文。
> 本章 3 讲讲的是同一件事的三个角度：**代码里哪些字符真正参与语义**。

---

## 一、空白字符（没人看，但它在）

- 空白字符只有三种：**空格、换行（Enter）、制表符（Tab）**。
- 它们**只起分隔作用，不是语法成分** → 所以可有可无、可多可少、可在任意行。
- 对照组：删**分号** → 报错；删**空格** → 正常编译。**分号是语法成分，空格不是。**
- 三种写法（无空格 / 一空格 / 多空格+换行）**语法上完全等价**。
- 但为了**可读性**，推荐：**运算符左右各留一个空格**。
- 编译报错要看**输出窗口**，不是错误列表窗口。

## 二、注释（人能看懂，编译器当不存在）

- **注释 = 只有人懂、编译器当它不存在** → 效果等于**把那行代码挖走**。
- **`//` 单行注释**：只对**它后面**的本行内容生效，前面的代码照常编译。
- **`/* ... */` 多行注释**：中间全部注释掉。
- ⚠️ **多行注释不能嵌套**：遇到第一个 `*/` 就结束，里面的 `/*` 不算数。
- 两个用途：**解释代码**（为什么这么做）、**临时屏蔽代码**（可逆，删了就回不来）。
- 编辑器里的绿色只是**着色**，不是语法，别拿颜色当判据。

## 三、关键字与标识符

- **关键字**：C 语言**语法规定**的，有固定含义，**共 32 个**（C89；C99/C11 又加了几个）。
- **标识符**：**你自己起的**名字（变量名、函数名）。
- **C 语言大小写敏感**：`int` 是关键字，`Int` 就只是普通标识符（还会报"未声明"）。
- **标识符三条规则**：
  1. **不能和关键字重名**（大小写不同可以）
  2. **只能包含数字、字母、下划线**
  3. **开头不能是数字**
- 判定：`int` ❌ / `Int` ✅ / `3xy` ❌ / `xy3` ✅ / `x3y` ✅ / `x` ✅ / `_` ✅ / `3` ❌
- ⚠️ `_` 开头**语法合法但别用** —— `_` + 大写字母、`__` 开头都是**保留给编译器/标准库**的。

## 四、这一章的思路

```
空白字符  → 不参与语义（可删）
注释      → 不参与语义（编译器看不见）
标识符    → 参与语义，但有命名约束
分号、关键字、括号 → 真正的语法成分
```

> **遇到"这行为什么报错"时先问一句：出错的那个字符，是语法成分吗？**

## 五、这一章的三条主线

```
① 空白：能省则省，但别省分号
② 注释：// 与 /* */，屏蔽而不是删除
③ 名字：不撞关键字、只用数字字母下划线、不以数字开头
```

> 掌握标志：**能不看笔记说出标识符的三条规则，并用正反例各举两个。**
