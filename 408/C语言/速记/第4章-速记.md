# 第4章 速记

> **一章压成一页，5 分钟过一遍。** 本章 11 讲、9 份笔记，是全课地基。
> 看不懂的条目，去翻对应笔记正文。

---

## 一、数据对象只有两类

- **常量**：不可修改。**变量**：可修改。
- **字面值常量四种**：整数 `1234`、浮点 `3.14`、**字符 `'a'`（单引号，一个）**、**字符串 `"abc"`（双引号，多个）**。
- 给常量赋值 → 报错「**等号的左操作数必须为左值**」（编译期就挡住）。
- ⚠️ **魔法数**：代码里写死一个数字，读的人看不出它是什么 → 改成 3 时容易把圆周率的 3 也改掉。

## 二、符号常量与宏

- **`#define 名字 值`**：给字面值起名字。**`define` 后、值前各一个空格，末尾不加分号。**
- 原理是**宏**：在**预处理阶段**（编译之前）做**文本替换**。
- 好处：改一处、全改；干掉魔法数。
- ⚠️ **宏只替换、不计算、不检查** → `#define R 3+1` 会让 `PI*R*R` 变成 `3*3+1*3+1`（优先级被破坏，48 变 13）。
- **所以：宏里的表达式一律加括号** `#define R (3+1)`。

## 三、变量

- **变量 = 一片有名字的内存区域。**
- **两个要素**：**名字**（怎么找到它）+ **数据类型**（占多大、里面 0/1 怎么解释）。
- `sizeof` 是**运算符**（不是函数），能求类型或变量的**字节数**。
- **初始化**：在**定义语句里**赋初值。**赋值**：在**其他位置**用新值覆盖旧值。
- 同一个 `=`，位置不同含义不同 —— 这个认识对 `*`、`&` 同样适用。
- `i = i + 1`：**先算右边，再写回左边**。

## 四、数据类型（本章主体）

- 基本类型 = **整数**（有符号 `char < short < int < long < long long`；无符号加 `unsigned`）+ **浮点**（`float` 单精度、`double` 双精度）。
- **字符的本质是整数**：`char` 既是最小整数类型，又是字符类型。
- **进制**：默认十进制；**`0` 开头是八进制**（`01234` = 668）；**`0x` 开头是十六进制**（`0x1234` = 4660）。
  - 八进制只能用 0~7；十六进制用 0~9 + a~f（大小写都行）。
- ⚠️ **`int` / `long` 的长度随平台变**，别写死；VS x64 下是 1/2/4/4/8 字节。
- **范围公式**：n 比特有符号整数 = **[−2^(n−1), 2^(n−1)−1]**。
- **估算**：`2^10 ≈ 1000` → `2^31 ≈ 20 亿` → **int 约 ±21 亿**。
- **溢出**：有符号最大 +1 → **负数**；无符号最大 +1 → **0**。**不会报错，只是结果不可信。**
- **无符号**：范围 `0 ~ 2^n−1`，打印用 **`%u`**（`%d` 只用于有符号）。

## 五、浮点数：近似值

- `float` 4 字节、`double` 8 字节；打印用 `%f`，控制位数用 **`%.Nf`**。
- **整数精确，浮点近似** —— 因为内存有限，无限小数存不下，只能约等于。
- ⚠️ **浮点数不能比较相等**（`==` 几乎永远不成立），要比差的绝对值。
- **有效数字**：float 约 **6 位**，double 约 **15 位**。
- ⚠️ **精度丢失**：两个数绝对值相差很大时加减，**小的那个被吃掉**（`1.2345e10 + 20` 还是 `1.2345e10`）。
- 科学计数法：`1.2345e10` = 1.2345 × 10¹⁰。

## 六、字符与 ASCII

- 字符常量用 `'a'`，打印用 **`%c`**。
- **`'a'` = 97、`'A'` = 65、`'0'` = 48** —— ⚠️ **字符 `'0'` 不是数值 0**。
- **大小写差 32**：小写 = 大写 + 32。
- **字符相减 = 整数相减**（`'3' - '1'` = 2）。
- 转义字符（写出来的 ≠ 代表的）：`\n` 换行、`\r` 回车（回行首）、`\b` 退格、`\t` 制表、`\\` 反斜杠。
- **ASCII 共 128 个**（0~127），占 7 比特。

## 七、字面值的默认类型（最会坑人）

- **整数默认 `int`**（放不下才逐级升级）；**浮点默认 `double`**（哪怕只有 3 位有效数字）。
- ⚠️ **两边都是 `int`，结果一定是 `int`** → `1/2` = **0**，不是 0.5。
  - 修正：`1.0 / 2`（让至少一边是浮点）。
- ⚠️ **`long long ll = a * b;` 救不了溢出** —— 乘法**先算完**再赋值，中间已经溢出。
  - 修正：`(long long)a * b`（**先转换一个操作数**，另一个会自动提升）。
- `long long` 的占位符是 **`%lld`**。

## 八、这一章的三条主线

```
① 类型感    写一个值 → 它是什么类型？能装多大？装不下会怎样？
② 精确性    整数精确、浮点近似；除法是整数除法还是浮点除法
③ 默认值    默认 int / 默认 double 是所有"算错"事故的源头
```

> **掌握标志**：能不看笔记解释 `1/2` 为什么等于 0、`131072*131072` 为什么等于 0，并写出两种修正写法。
