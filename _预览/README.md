# 笔记预览（本地网页阅读器）

把整个笔记库渲染成**一个离线可用的网页**：`..\笔记预览.html`。

双击就能看，不需要联网、不需要装任何东西、不需要启动服务。

---

## 三种用法

| 场景 | 怎么做 |
|---|---|
| 只想看 | 双击上一层的 **`笔记预览.html`**（任何浏览器都行，推荐 Edge / Chrome） |
| 笔记改了，要看新的 | 双击 **`更新预览.bat`** → 重新生成并自动打开 |
| 边写边看（改完保存页面自动刷新） | 双击 **`实时预览.bat`** → 浏览器打开 `http://127.0.0.1:8180/`，关掉黑窗口即停止 |

> `更新预览.bat` 等价于在 `_预览` 目录里执行 `node src/build.mjs`；
> `实时预览.bat` 等价于 `node src/serve.mjs`。

---

## 页面里能做什么

- 左侧：目录树（可折叠、可拖宽）、按标题筛选
- **`Ctrl + K`** 或 **`/`**：全库全文搜索（标题 / 路径 / 正文，空格分词）
- 右侧：本页目录，滚动时高亮当前小节
- **`[`** / **`]`**：上一篇 / 下一篇
- **`t`**：浅色 / 深色切换（也可点左下角图标）
- `A−` / `A+`：正文字号；代码块右上角「复制」；点图片看大图
- 笔记之间的 `[xxx](yyy.md)` 链接是可以直接点的（包括锚点 `#小节`）
- `Ctrl + P` 打印 / 导出 PDF（已做打印样式）
- 阅读进度、上次读到哪篇（存在浏览器 localStorage）

## 目录结构

```
_预览/
├─ src/
│  ├─ build.mjs      生成器：扫描 .md → 渲染 → 打包成单文件 HTML
│  ├─ markdown.mjs   零依赖 Markdown 渲染器（表格 / 任务列表 / 代码块 / 锚点）
│  ├─ highlight.mjs  代码着色（java/c/cpp/kotlin/python/bash/powershell…）
│  ├─ app.css        界面样式（配色、字号、间距都在这里改）
│  ├─ app.js         交互（路由、搜索、目录、主题）
│  ├─ template.html  页面骨架
│  ├─ serve.mjs      本地实时预览服务
│  └─ verify.mjs     生成结果自检（断链、锚点、标签平衡、CSS 变量）
├─ 更新预览.bat
├─ 实时预览.bat
└─ README.md
```

产物只有一个：`../笔记预览.html`（约 3.8 MB，内容是全部笔记的 HTML 快照）。

## 一些实现上的取舍

- **单文件**：所有笔记内容和样式都内嵌在一个 HTML 里。好处是双击即用、好备份、百度同步不会漏；代价是**改完笔记必须重新生成**（所以才给了两个 bat）。
- **相对图片路径**：`.md` 里写的相对图片路径会按「笔记所在目录」解析成相对笔记库根目录的路径，所以在 `笔记预览.html` 里图片能正常显示（`.img/*.svg` 那批图也在）。
- **绝对路径**：`.photo` 里有些老笔记写死了 `D:\...` 或 `file:///D:/...` 的图片路径，只要还在这个笔记库里就能自动转成相对路径。
- **零依赖**：没有 npm 包，Node.js 只用来做构建（`node --version` 能看到 20+ 就行）。

## 已知情况（不是 bug）

- `.photo` 里 2019 年的老笔记引用了 `图片/const成员.png`、`assets/animation.png` 等文件，**原文件本来就不在**（有的是 `.wydl` 百度未下完的临时文件），页面会显示「图片无法加载」占位。
- 部分老笔记有 `http://` 外链图片，**离线时显示不出来**，联网才可见。
- `.photo` 里的课程资料有 28 篇，属于历史存档，在左侧目录里排在最后。

## 自检

改过 `src/` 之后跑一下：

```
node _预览\src\verify.mjs
```

它会检查：内嵌数据能否解析、模板标签是否平衡、JS 引用的 id 是否存在、
221 条内部链接是否可达、图片路径是否存在、正文有没有残留的 Markdown 标记、CSS 变量是否都有定义。
