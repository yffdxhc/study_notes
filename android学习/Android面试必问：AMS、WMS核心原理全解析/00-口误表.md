# ASR 口误表（语音转写勘误）

> 逐字稿是**语音转写**，专有名词错得厉害。**读文稿时按右列认；搜源码时按真实拼写搜，千万别按左列搜。**
>
> 本表汇总全部 13 讲。每篇笔记头部只列本篇涉及的那几条，完整版在这里。

## 怎么用

| 场景 | 做法 |
|---|---|
| 读文稿读不通 | 先查本表 |
| 在源码里搜符号 | 一律用**右列**的真实拼写 |
| 发现新口误 | 补到对应讲次，同时更新那篇笔记头部的「⚠️ 文稿口误」 |

## 四、经验：怎么判断一个词是不是口误

1. **看着像英文音译，但不像任何真实类名** → 大概率口误
2. **同一个概念在文中有 3 种以上写法** → 全是口误，去 AOSP 找真实拼写
3. **搜源码搜不到** → 换拼写（类名 + `.java` 去 cs.android.com 搜）
4. **别把口误当结论**：文稿说"`a的toDisplay`"，实际是 `relayout` 这一族方法（见第2章 03）
