## 一、这个模块是什么

**一套面试导向的 Framework 原理课**，主线是**一条启动链路**：

```
上电 → init → zygote → system_server → AMS/ATM → Activity 启动
                                                    ↓
                                          Window 创建 → ViewRootImpl → 绘制
```

- **第 1 章 AMS 篇**（6 讲）：进程怎么起来、Activity 怎么启动、生命周期和栈
- **第 2 章 WMS 篇**（7 讲）：Window 何时创建、ViewRootImpl 这座桥、UI 刷新与绘制

> **学习价值**：这两章合起来，正好是 [Android-Framework-地图](../../Android-Framework-地图.md) 里
> **「进程和服务怎么起来的」+「界面怎么上屏」两条主线的展开版**。

### 4.1 什么时候配图

> **文字表达吃力的地方才画，不是每篇都配。**

| 适合画                      | 不适合画       |
| ------------------------ | ---------- |
| **时序 / 调用链**（谁先谁后、跨几个进程） | 单个名词解释     |
| **时间线**（什么时候产生什么对象）      | 表格已经能说清的对照 |
| **队列 / 屏障这类结构关系**        | 纯结论罗列      |
| **层级包含关系**               | —          |

**图的格式**：手写 SVG，放在**每章目录自己的 `.img\`** 里。

> **⚠️ 两条硬规矩（实测踩过，2026-11-09）：**
> 
> 1. **引用只用 `./` 同级** —— Typora 里 `../` 的图片不生效
> 2. **文件名不能带空格** —— 否则 Typora 把空格编码成 `%20`、图加载失败，笔记里会留下 `![loading-ag-xxx](...)` 占位
> 
> 命名统一 `NN-中文名.svg`（用 `-` 代替空格）。
