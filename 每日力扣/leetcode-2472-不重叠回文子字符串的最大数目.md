# 2472. 不重叠回文子字符串的最大数目

> 题目：
> 
> 给你一个字符串 `s` 和一个 **正** 整数 `k`。
>
> 从字符串 `s` 中选出一组满足下述条件且 **不重叠** 的子字符串：
> - 每个子字符串的长度 **至少** 为 `k`。
> - 每个子字符串是一个 **回文串**。
>
> 返回最优方案中能选择的子字符串的 **最大** 数目。
>
> **子字符串** 是字符串中一个连续的字符序列。
>
> 示例 1：`s = "abaccdbbd"`, `k = 3` → 输出 `2`（选 `"aba"` 和 `"dbbd"`）
> 示例 2：`s = "adbcda"`, `k = 2` → 输出 `0`（不存在长度至少为 2 的回文子串）
>
> 提示：`1 <= k <= s.length <= 2000`；`s` 仅由小写英文字母组成

> 📖 **阅读顺序说明**：这份文档按"从零开始"来写——
> 第一章先弄懂三个条件分别是什么意思；
> 第二章用人脑手算示例，发现"这其实是两道经典题的合体"；
> 第三章把问题拆成两步；
> 第四、五章分别给出两种做法（第一种好想，第二种是官方思路）；
> 第六、七章对比与走查；第八章回答疑问；
> 第九、十章是复杂度和易错点。
>
> 如果你时间紧，直接跳到 **第四章** 看推荐做法。

## 一、先把题目读懂（三个条件 + 一个规模提示）

### 1.1 条件一：必须是"子字符串"= 连续的

题目特别强调了一句：

> **子字符串** 是字符串中一个连续的字符序列。

所以不能像子序列那样"跳着选"，只能选**连续的一段**。比如 `"aba"` 可以，`"aa"`（从 `"aba"` 里跳着取）不行。

### 1.2 条件二：每个子串必须是回文，且长度至少为 k

- **回文**：正着读反着读一样，比如 `"aba"`、`"dbbd"`；
- **长度 ≥ k**：`k` 是给定的下限。注意是 **至少**，长度 `k+1`、`k+2`… 都合法。

### 1.3 条件三：互不重叠

选中的子串**不能共用任何字符**。例如 `"abcba"` 里的 `"bcb"`（下标 1~3）和 `"abcba"`（下标 0~4）就重叠了，不能同时选。

### 1.4 为什么不能"见到回文就选"？

一个很自然的错误想法是：从左往右扫，遇到回文就选。

```
s = "abaccdbbd", k = 3
从左扫：遇到 "aba"（下标 0~2）→ 选它
       接着从下标 3 继续，再也没找到长度 ≥3 的回文
       结果 = 1
但正确答案是 2（"aba" 和 "dbbd"）
```

问题在于：**选得太早、太长，会挡住后面**。所以必须用**区间调度**的思路来权衡——这正是第三章要讲的。

### 1.5 提示里最重要的一条：`n <= 2000`

`n` 最大 2000，意味着：

- `O(n²) = 4 × 10⁶` 的算法完全够用；
- `O(n²)` 的空间（一张 `2000 × 2000` 的表）也才 4 MB 左右，可以接受。

> 所以这题的标准解法就是 **`O(n²)` 的预处理 + `O(n²)` 的 DP**。

## 二、人脑会怎么算？

### 2.1 手算示例 1

`s = "abaccdbbd"`（下标 0~8），`k = 3`。先把**所有长度 ≥ 3 的回文子串**列出来：

| 子串 | 下标区间 | 长度 |
|---|---|---|
| `"aba"` | [0, 2] | 3 |
| `"dbbd"` | [5, 8] | 4 |

（检查一下别的：`"cc"` 只有长度 2 不够；`"acc"`、`"ccd"`、`"dbb"`、`"bbd"` 都不是回文；更长的如 `"abacc"`、`"baccd"` 等也都不是。）

现在要在这些回文区间里挑**最多**个互不重叠的：

- 选 `[0,2]` 和 `[5,8]` → 两者不重叠（2 < 5）✅ → **2 个**

还能有 3 个吗？3 个长度 ≥3 的区间至少占 9 个字符，而 `n = 9`，那就必须每个恰好长 3 且完全铺满：`[0,2] [3,5] [6,8]`。但 `[3,5] = "ccd"` 不是回文 → 不行。

所以答案是 **2** ✅

### 2.2 手算示例 2

`s = "adbcda"`，`k = 2`。长度 ≥ 2 的子串里有没有回文？

- 长度 2：`"ad"`、`"db"`、`"bc"`、`"cd"`、`"da"` —— 没有相等的一对；
- 长度 3：`"adb"`、`"dbc"`、`"bcd"`、`"cda"` —— 首尾都不等；
- 长度 4、5：同理首尾不等；
- 长度 6：`"adbcda"` —— 首尾都是 `a` ✅，但里面 `"dbcd"` 首尾是 `d` 和 `d` ✅，再里面 `"bc"` 不等 ❌ → 不是回文。

所以答案是 **0** ✅

### 2.3 从手算里发现：这题是两道经典题的合体

回头看第 2.1 节，我其实做了两件独立的事：

1. **找出所有回文子串** → 这需要"回文识别"的能力（经典题：647 回文子串）；
2. **在这些区间里挑最多不重叠的** → 这是"区间调度"（经典题：435 无重叠区间）。

> **所以这题的解法就是：先做第 1 件事，把每个回文变成一个"区间"；再把问题交给第 2 件事。**

## 三、核心：把问题拆成两步

```
原问题：选最多互不重叠的、长度 ≥ k 的回文子串
          ↓ 拆解
第一步：求出所有长度 ≥ k 的回文子串 —— 每个都是一个区间 [i, j]
第二步：在这些区间里，选最多两两不重叠的
```

第二步是标准的 **"最多不重叠区间"** 问题，有成熟的 DP 套路（第五章的贪心也是它）。

## 四、方法一（推荐，最好想）：回文表 + DP

### 4.1 第一步：预处理回文表

用区间 DP 求出 `isPal[i][j] = s[i..j] 是否是回文`。

**怎么递推？** 一个子串是回文，当且仅当：

```
两端字符相同  s[i] == s[j]
      且
里面那一层也是回文  isPal[i+1][j-1]
```

特殊情况：长度 1（`i == j`）必然是回文；长度 2（`j - i == 1`）只要两端相等就是回文——这两种情况**没有"里面那一层"**，直接成立。

合起来：

```
isPal[i][j] = (s[i] == s[j]) && (j - i < 2 || isPal[i+1][j-1])
```

**枚举顺序很关键**：`isPal[i][j]` 用到了 `isPal[i+1][j-1]`——行号更大、列号更小。所以外层 `i` 必须**从大到小**枚举，才能保证用到的那个值已经算好了。

### 4.2 第二步：设计 DP

设 `dp[i]` = **只看前 `i` 个字符**（也就是 `s[0..i-1]`）时，最多能选几个。

考虑第 `i` 个字符（下标 `i-1`）用不用：

| 选择 | 结果 |
|---|---|
| **不用它** | 那就是前 `i-1` 个字符的答案：`dp[i-1]` |
| **用它** | 那就选一个**以 `i-1` 结尾**的回文 `s[j..i-1]`（要求 `i - j >= k`），选完之后前面只能用 `s[0..j-1]`：`dp[j] + 1` |

于是转移方程：

```
dp[i] = max( dp[i-1],  max{ dp[j] + 1 : j + k <= i  且  isPal[j][i-1] } )
```

答案是 `dp[n]`。

### 4.3 手推示例 1 的 DP

`s = "abaccdbbd"`，`k = 3`。只有两个"有用"的回文：`[0,2]` 和 `[5,8]`。

| i | 可选的 j（`isPal[j][i-1]` 且 `i-j>=3`） | dp[i] |
|---|---|---|
| 0 | — | 0 |
| 1 | — | 0 |
| 2 | — | 0 |
| 3 | j=0（`"aba"`）→ `dp[0]+1 = 1` | **1** |
| 4 | 无 | 1（继承 dp[3]） |
| 5 | 无 | 1 |
| 6 | 无 | 1 |
| 7 | 无 | 1 |
| 8 | 无 | 1 |
| 9 | j=5（`"dbbd"`）→ `dp[5]+1 = 2` | **2** |

最终 `dp[9] = 2` ✅

### 4.4 代码

```java
class Solution {
    public int maxPalindromes(String s, int k) {
        int n = s.length();

        // 1) 预处理：isPal[i][j] = s[i..j] 是否为回文
        boolean[][] isPal = new boolean[n][n];
        for (int i = n - 1; i >= 0; i--) {          // i 必须从大到小
            for (int j = i; j < n; j++) {
                if (s.charAt(i) == s.charAt(j) && (j - i < 2 || isPal[i + 1][j - 1])) {
                    isPal[i][j] = true;
                }
            }
        }

        // 2) dp[i] = 前 i 个字符里最多能选几个
        int[] dp = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            dp[i] = dp[i - 1];                       // 不选以 i-1 结尾的子串
            for (int j = 0; j + k <= i; j++) {       // 枚举起点 j，保证长度 >= k
                if (isPal[j][i - 1]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
        }
        return dp[n];
    }
}
```

```python
class Solution:
    def maxPalindromes(self, s: str, k: int) -> int:
        n = len(s)

        # 1) 回文表
        isPal = [[False] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):               # i 必须倒序
            for j in range(i, n):
                if s[i] == s[j] and (j - i < 2 or isPal[i + 1][j - 1]):
                    isPal[i][j] = True

        # 2) dp
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            dp[i] = dp[i - 1]
            for j in range(i - k + 1):               # j + k <= i
                if isPal[j][i - 1]:
                    dp[i] = max(dp[i], dp[j] + 1)
        return dp[n]
```

## 五、方法二（官方思路）：一个漂亮的洞察

官方题解用了一个更妙的观察，把空间砍到 `O(n)`。

### 5.1 洞察：长回文都能"缩"成 k 或 k+1

> 如果 `s[a..b]` 是长度 `L ≥ k + 2` 的回文，那么**去掉首尾各一个字符**得到的 `s[a+1..b-1]` **也是回文**，长度变成 `L - 2`。

为什么？因为 `s[a..b]` 是回文，所以首尾相等 `s[a] == s[b]`；砍掉它俩之后，剩下的中间部分仍然是回文结构。反复砍，长度每次减 2，最终会落到 **`k` 或 `k+1`**（取决于 `L` 与 `k` 的奇偶差）。

### 5.2 为什么"缩短"不影响答案

- **仍然是合法回文**：长度 `k` 或 `k+1` 都 ≥ `k`，满足条件；
- **仍然不重叠**：把选中的区间**缩小**，只会让它更不容易和别人冲突，所以原本合法的方案依然合法；
- **数量不变**：缩短不会让区间消失。

> **结论：一定存在一个最优解，其中每个选中的回文长度恰好是 `k` 或 `k+1`。**
> （注意这是**论证出来的性质**，不是题目要求——题目允许任意长度 ≥ k。）

### 5.3 于是只需考虑两种长度

既然只用长度 `k` 和 `k+1`，那对于**固定长度**，区间越靠左就**结束得越早**；而"最早结束优先"正是区间调度贪心的正确策略（结束越早，后面留的空间越大）。

所以从某个起点 `start` 出发：

- 在 `start` 及之后找**第一个**长度为 `k` 的回文，选它，从它后面继续；
- 或者找**第一个**长度为 `k+1` 的回文，选它，继续；
- 两者取最大。

### 5.4 代码

```java
class Solution {
    private String s;
    private int k;
    private int[] memo;

    public int maxPalindromes(String s, int k) {
        this.s = s;
        this.k = k;
        memo = new int[s.length() + 1];
        Arrays.fill(memo, -1);
        return dfs(0);
    }

    /** 从下标 start 开始（只看 start 之后的字符），最多能选几个 */
    private int dfs(int start) {
        if (start + k > s.length()) return 0;        // 剩下的长度不够 k 了
        if (memo[start] != -1) return memo[start];

        int ans = 0;
        // 只需考虑长度恰好为 k 或 k+1 的回文
        for (int len = k; len <= k + 1; len++) {
            for (int i = start; i + len <= s.length(); i++) {
                if (isPal(i, i + len - 1)) {
                    ans = Math.max(ans, 1 + dfs(i + len));
                    break;                            // 同长度取最靠左（最早结束）
                }
            }
        }
        return memo[start] = ans;
    }

    private boolean isPal(int l, int r) {
        while (l < r) {
            if (s.charAt(l) != s.charAt(r)) return false;
            l++;
            r--;
        }
        return true;
    }
}
```

> **取舍建议**：方法一逻辑直白、能独立想出来，**面试先写方法一**；方法二空间更省、代码更短，但要先想通"长回文可以缩"这个洞察。

## 六、两种方法对比

| | 方法一：回文表 + DP | 方法二：洞察 + 记忆化 |
|---|---|---|
| 核心 | 预处理所有回文 → 区间调度 DP | 只需长度 k / k+1 → 最早结束优先 |
| 时间 | `O(n²)` | `O(n²)` |
| 空间 | `O(n²)`（回文表） | `O(n)` |
| 好想程度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| 通用性 | 强（换条件也能改） | 依赖"回文可缩短"这一性质 |

## 七、拿示例 1 走一遍（方法二）

`s = "abaccdbbd"`，`k = 3`，长度 9。

```
dfs(0)：
  长度 3：从 i=0 往后找 → s[0..2] = "aba" 是回文 ✅
          候选 = 1 + dfs(3)
  长度 4：从 i=0 往后找 → "abac"✗ "bacc"✗ "accd"✗ "ccdb"✗ "cdbb"✗ "dbbd"✅（i=5）
          候选 = max(1 + dfs(3), 1 + dfs(9)) = 1 + dfs(3)

dfs(3)：
  长度 3：i=3..6 → "ccd"✗ "cdb"✗ "dbb"✗ "bbd"✗ → 没有
  长度 4：i=3..5 → "ccdb"✗ "cdbb"✗ "dbbd"✅（i=5）
          候选 = 1 + dfs(9) = 1

所以 dfs(0) = 1 + 1 = 2 ✅
```

选出的正是 `"aba"` + `"dbbd"`，与题目解释一致。

## 八、常见疑问 Q&A

**Q1：为什么回文表递推要 `i` 从大到小枚举？**
因为 `isPal[i][j]` 依赖 `isPal[i+1][j-1]`——**行号更大**。`i` 倒序枚举时，第 `i+1` 行已经全部算好了。

**Q2：DP 里为什么是 `dp[j] + 1`，不是 `dp[i-1] + 1`？**
因为选中的回文是 `s[j..i-1]`，它占了从 `j` 到 `i-1` 这一段。选完之后**只能用 `s[0..j-1]`**，所以要看 `dp[j]`，而不是前一个字符。

**Q3：子串长度可以大于 k 吗？**
可以，题目是"**至少** k"。方法一直接支持任意长度；方法二则是**论证出**"只考虑 k 和 k+1 就够了"（见 5.1~5.2）。

**Q4：回文长度为什么能缩到 `k` 或 `k+1`，而不是别的？**
因为每次砍掉首尾各一个字符，长度正好减 **2**（奇偶性不变）。所以从任意 `L ≥ k` 出发反复减 2，落点只能是 `k` 或 `k+1`——绝不会落在 `k+2` 或更小。

**Q5：能不能用纯贪心一次扫完（不回退）？**
可以，但要建立在"只需考虑长度 k / k+1"这个洞察之上，且要处理两种长度的取舍（方法二就是做了这件事）。**不假思索的贪心（见到回文就取）会错**，见 1.4 的反例。

**Q6：`n = 2000` 会不会超时或超内存？**
不会。`O(n²) = 4 × 10⁶` 次运算；`boolean[2000][2000]` 约 4 MB。两种方法都远在限制内。

**Q7：`k = 1` 时答案是什么？**
每个单字符都是长度 1 的回文，且互不重叠，所以可以把整个串切成 `n` 个单字符 → 答案是 `n`。（方法一里 `j + 1 <= i` 恒成立，`isPal[j][j]` 恒为 true，能自然算出。）

## 九、复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| 一（回文表 + DP） | `O(n²)` | `O(n²)` |
| 二（记忆化 + 长度 k/k+1） | `O(n²)` | `O(n)` |

- 回文表预处理 `O(n²)`；DP 每个右端点枚举起点 `O(n)`，合计 `O(n²)`；
- 方法二的每个状态 `dfs(start)` 内层最多扫描 `O(n)`，状态数 `O(n)`，也是 `O(n²)`。

> `n ≤ 2000` → 最多约 400 万次运算，轻松通过。

## 十、易错点清单

1. **回文表枚举方向写反** ❗ `isPal[i][j]` 依赖 `isPal[i+1][j-1]`，`i` 必须**从大到小**；
2. **长度条件写成 `>`**：题目是"至少 k"，代码里是 `i - j >= k`（写成 `j + k <= i` 更不易出错）；
3. **忘了"不重叠"**：回文 `s[j..i-1]` 选完后前面只能用 `s[0..j-1]`，所以是 `dp[j] + 1`；
4. **以为必须恰好长度 k**：任意长度 ≥ k 都合法（方法二的"只考虑 k/k+1"是论证结论）；
5. **贪心时没考虑两种长度**：只取长度 k 或只取长度 k+1，都可能不是最优 → 要取两者最大值；
6. **方法二忘了 `break`**：同长度要取最靠左的那个，不 `break` 会多算很多次；
7. **边界 `k > n`**：答案是 0（方法二的 `start + k > s.length()` 天然挡住）；
8. **把"子字符串"当"子序列"**：题目要求**连续**，不能跳着选。

## 十一、举一反三

这类"**回文 + 区间/分割**"的题是一整个家族，套路高度一致：

| 题目 | 变化点 |
|---|---|
| 2472 本题 | 选最多不重叠的回文（长度 ≥ k） |
| 5 最长回文子串 | 只求最长的那个 |
| 647 回文子串 | 数回文子串的**个数** |
| 132 分割回文串 II | 最少分割次数（同样是"回文 + DP"） |
| 1278 分割回文串 III | 分成 k 段，最少修改次数 |
| 435 无重叠区间 / 1235 规划兼职工作 | 纯区间调度（本题第二步的原型） |

**记住这个模式**：

> 当一道题同时要求"**某种结构**"和"**互不重叠/分割**"时，通常都能拆成两步：
> **① 预处理出所有满足结构的区间；② 在区间上做调度 DP。**
> 第一步用 `O(n²)` 的区间 DP（比如回文表），第二步用 `O(n²)` 的调度 DP。

## 附一：一句话总结

> 先用区间 DP 求出所有回文子串（`isPal[i][j] = s[i]==s[j] && (j-i<2 || isPal[i+1][j-1])`），把每个长度 ≥ k 的回文看成一个区间；再在区间上做调度：`dp[i] = max(dp[i-1], dp[j]+1)`（`s[j..i-1]` 是回文且长度 ≥ k）。全程 `O(n²)`。

## 附二：方法论——把"复合条件"拆成两步

> 这题真正的难点不在算法，而在**没意识到它可以拆**。

题目一次性给了三个约束：**回文 + 长度 ≥ k + 不重叠**。看起来是个大杂烩，但如果分层看：

| 层 | 要求 | 用什么解决 |
|---|---|---|
| 第一层 | 找出所有回文 | 区间 DP（回文表） |
| 第二层 | 长度 ≥ k | 在枚举时加一个条件即可 |
| 第三层 | 选最多不重叠 | 区间调度 DP / 最早结束贪心 |

**拆开之后，每一层都是见过的老题**，难度瞬间从"困难"降到"两个中等题相加"。

> 这个思路在很多困难题里都管用：
> - **3414 不重叠区间的最大得分** = "带权区间调度" + "字典序最小方案"两层；
> - **本题** = "回文识别" + "区间调度"两层；
> - **3871 统计范围内的逗号 II** = "每个数字贡献几次" + "换一个求和顺序"两层。

**遇到困难题，先别急着想一个"大算法"，先问自己：这道题是不是由几个我认识的小问题拼起来的？**
