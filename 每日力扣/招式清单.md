# 每日力扣 · 招式清单

> **用途**：每做一题，只在下面加一行——一句"招式名" + 关键坑。复习时只看这一页。
>
> **原则**：记**思路**，不记代码。代码会忘，思路能重新推。

## 使用说明（三条规则）

1. **做完立刻加一行**：趁热写，只写一句话。写不出来，说明还没真懂；
2. **每周挑两天重看这一页**（各 10 分钟）——比多做两道新题有用，它防的是"做完就忘"；
3. **文档可以归档，招式不能丢**：`归档/` 里的题目详解随它去，这一页永远放根目录。

| 3414 | 不重叠区间的最大得分 | **排序 + 二分 `nxt` + 从后往前 DP**，状态里连"方案"一起存 | 相容是**严格** `r < l`；得分用 `long`；并列比字典序 |
| 2472 | 不重叠回文子字符串的最大数目 | **复合题拆两层**：① 回文表预处理 ② 区间调度 DP（`dp[i] = max(dp[i-1], dp[j]+1)`） | 回文表 `i` 必须**倒序**；选完 `s[j..i-1]` 后只能用 `dp[j]`；长度是**至少** k |
| 1621 | 大小为 K 的不重叠线段的数目 | **看最后一个点用不用**：`dp[i][j] = dp[i-1][j] + Σdp[t][j-1]`，相减化简成 `2dp[i-1][j] − dp[i-2][j] + dp[i-1][j-1]` | **端点可重合**，所以求和到 `t=i-1`；Java 有减法要 `+MOD`；闭式解 `C(n+k−1,2k)` |

## 二、跨题方法论（真正需要背下来的）

### ① 递归 vs 循环怎么选

> **不是"哪类题用什么"，而是"依赖结构长什么样"。**

| 依赖结构 | 能否预知计算顺序 | 写法 |
|---|---|---|
| 一条直线（数组/字符串） | 能 | **循环** |
| 二维网格（依赖左、上） | 能（按行列递增） | **双层循环** |
| 树（依赖两个孩子） | **不能**（取决于树形） | **递归** |

**问自己三个问题**：数据是不是递归定义的？顺序能否提前写死？会不会分叉？
（两者可互换：115 能写成递归 + 记忆化，2265 能用栈写成循环。）

### ② 枚举答案 vs 枚举素材

| | 枚举素材（输入） | 枚举答案（输出） |
|---|---|---|
| 适合 | 答案空间大 | **答案空间小** |
| 去重 | 通常要 Set | **天然不重复** |
| 例子 | 三重循环下标 | `100~999` 的偶数 |

> 先估一下"答案空间有多大"，小就果断枚举答案。

### ③ 枚举操作 vs 枚举对象对

> 当"枚举操作 → 检查结果"太贵时，反过来：**结果是哪些对象构成的？每个结果需要什么操作？**
> 把"操作"变成被统计的量，而不是被枚举的维度。

- 835：重叠点 ← 一对 1（操作 = 坐标差）
- 3414：方案 ← 选中的区间（约束 = 不重叠）

### ④ 要输出"字典序最小方案"的通用四步

1. 状态里**同时**存"最优值"和"方案本身"；
2. 转移时先比最优值，**值相同再比方案字典序**；
3. 自问：只留一个方案会不会丢最优？
4. **论证安全性**（3414 靠的是：权重都是正数 ⇒ 同分解不互为前缀 ⇒ 并入同一批新元素不翻转字典序）。

> ⚠️ 第 4 步不能无脑照搬——权重含 0 或负数时结论可能不成立。

### ⑤ MOD 为什么是 `10^9 + 7`

- 首先是**题目指定的**；
- 其次它是**约 10 亿的大质数**：`int` 相加不溢出、`long` 相乘不溢出，且质数让"除法求逆元"有退路；
- 取模可以边算边取（`(a+b)%p == (a%p+b%p)%p`）；
- Java 负数取模要 `+ MOD` 修正；Java 的 `1_000_000_007` 就是 `1000000007`（下划线只是好看）。

## 三、该主攻什么（时间有限版）

| 优先级 | 招式 | 时间占比 |
|---|---|---|
| **S** | DP 状态设计（一维 → 二维） | 40% |
| **S** | 递归 + 后序汇总 | 25% |
| A | 枚举 + 哈希去重/计数 | 15% |
| A | 排序 + 二分找边界 | 10% |
| B | 双指针 / 滑动窗口 / BFS / 贪心 | 10% |
| ~~C~~ | 位运算、单调栈、线段树、bitset 常数优化 | **0%，放弃** |

**同题多解时**：① 先写出朴素解（保底）→ ② 再看最优解的**那一个转化点** → ③ 跳过常数优化。

**选题比例**：70% 中等 + 20% 简单 + 10% 困难。困难题当天只要求"看懂 + 抄一遍能过"。

## 四、每天 30 分钟的最小流程

| 时间 | 做什么 |
|---|---|
| 0–5 分 | 读题，纸上写"输入/输出/约束"和第一反应的暴力做法 |
| 5–20 分 | 写代码。卡住**超过 10 分钟就看题解，且只看到"第一个关键点"**就停 |
| 20–25 分 | **合上题解重写一遍关键部分**（不可省略，看懂 ≠ 会写） |
| 25–30 分 | 在本文档的招式总表里加一行 |
