# 口误表（全库）

> **收什么**：语音转写（ASR）把专有名词听错的地方。
> **怎么用**：**读文稿安右列认；搜源码/搜关键词一律用真实拼写，别按左列搜。**
>
> 配套：[术语表](术语表.md)（一个字/词本身指多个东西，不是听错）

## 两个模块的差别

| 模块 | 口误密度 | 原因 |
|---|---|---|
| **Android 面试必问（AMS/WMS）** | **很高** | 纯直播口述，没讲义，英文术语密集 |
| **408 C 语言（王道督学营）** | **较低** | 有讲义/板书配合，老师会写出来，转写压力小 |

所以下面 Android 部分占大头；408 只有 3 处，但都是搜不到的关键词。

# 三、怎么判断一个词是不是口误

1. **看着像英文音译，但不像任何真实标识符** → 大概率是口误
2. **同一概念在文中有 3 种以上写法** → 全是口误，去源码/标准找真实拼写
3. **搜源码/搜索引搜不到** → 换拼写再搜
4. **别把口误当结论**：文稿说「`a的toDisplay`」，实际是 `relayout` 这一族方法
5. **数字类口误**（如「幺三幺零七二」）→ 按读音还原成阿拉伯数字
